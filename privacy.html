🔒 隐私政策

最后更新日期：2026年7月26日

重要声明：Astras Search 是一个个人学习实验项目，旨在探索搜索聚合技术。本项目不收集、不存储任何用户个人数据，所有搜索请求均直接转发至第三方搜索引擎。

1. 数据收集声明

1.1 我们不收集的数据

  • 搜索关键词：您的搜索内容不会经过我们的服务器，直接由浏览器发送至目标搜索引擎。
  • IP 地址：我们不记录用户的 IP 地址或地理位置信息。
  • 个人身份信息：不收集姓名、邮箱、电话等任何可识别个人身份的信息。
  • Cookie：本站不使用 Cookie 或本地存储来追踪用户行为。

1.2 第三方可能收集的数据

当您点击搜索结果跳转至第三方搜索引擎时，以下平台可能会根据其各自的隐私政策收集数据：

  • Google：参见 Google 隐私政策
  • Bing (Microsoft)：参见 Microsoft 隐私声明
  • 百度：参见 百度隐私政策
  • DuckDuckGo：参见 DuckDuckGo 隐私政策

2. 技术实现说明

Astras Search 采用纯前端聚合跳转架构：

  • 搜索请求由您的浏览器直接发送至目标搜索引擎，不经过中间服务器。
  • 本项目无后端服务，不处理、不缓存任何搜索数据。
  • 页面加载后，所有交互均在本地完成，无网络请求发送至本项目服务器。

3. 第三方服务

本站托管于 GitHub Pages，GitHub 可能会记录访问日志（如 IP、User-Agent），详见 GitHub 隐私声明。

4. 数据保留

由于本项目不收集任何数据，因此不存在数据保留期限的问题。

5. 用户权利

您有权：

  • 随时停止使用本服务。
  • 通过浏览器开发者工具验证本站的网络请求行为。
  • 查阅本站完整源代码（GitHub 仓库）以确认隐私声明的真实性。
